# 🌫️ 赛博诡秘

> 在灰雾、魔药与疯狂之间，重开一段属于你的诡秘人生。

`cyber_mystery` 是一款《诡秘之主》主题的人生重开模拟器：选择出身与天赋，经历随机事件、接触非凡、消化魔药，最终走向凡人、圣者、天使、真神，或常理之外的旧日。

当前版本：`1.5.2` · 人生正文采用按年龄推进的第二人称短篇编排，晋升间隔会逐条保留更多事件，高序列晋升拥有途径专属场景。

**纯本地随机引擎 · 不调用 LLM · 不读取聊天内容**

---

## ✨ 本次版本亮点

- **16 种出身 × 16 种天赋**：从雾都贫民窟、班西灯塔到图铎遗迹；从灵视、银舌到封印物碎片。
- **更丰富的人生事件**：成长、危机、外神侵蚀、扮演、死亡与平凡晚年均已扩充，减少重复体验。
- **主题选择图卡**：出身使用「身份卷宗」风格，天赋使用「灵性档案」风格；16 项以超宽四栏布局收纳为一张图。
- **文学化人生正文**：人生会被编排成按年龄推进的第二人称诡秘短篇。序列 9–5 不再只显示一行升级记录，而会补足途径意象、力量变化与代价；每个晋升间隔优先保留扮演、危机、途径特色和能体现人物变化的事件，并按原始年龄逐条显示。接触、晋升、失控和终局等关键节点完整保留，正文最多保留 36 个独立年龄块。
- **高序列专属晋升**：序列 4、3、2、1 会根据途径呈现不同的权柄、意象和世界反馈；序列 0 进一步区分标准登神、吞噬相邻途径序列 0、吞噬源质和外神终点坍缩。
- **途径主题图卡**：正规途径使用各自色板与符号，外神途径使用星空/污染基底并叠加危险色；不同终局会显示稳定登神、异质融合、源质吞没或现实坍缩的不同文本框风格。
- **单图人生年鉴**：人生图卡固定使用 1520px 超宽三栏布局；从第一列自上而下读完，再进入下一列。无论内容多长都保持一张图输出。
- **可复现的随机人生**：带上种子，随机开局、角色选择与人生轨迹都会复现。

## 🚀 快速开始

```text
/诡秘 重开
```

依次选择出身与天赋后，插件会自动完成整段人生。

想立刻开局：

```text
/诡秘 重开 随机
/诡秘 重开 随机 20260817
```

第二条命令会以同一个种子完整复现随机角色与人生过程。

## 🎮 指令一览

| 指令 | 用途 |
|---|---|
| `/诡秘 重开` | 进入捏人流程：选择出身，再选择天赋 |
| `/诡秘 重开 随机 [种子]` | 随机角色并直接开始；可附种子复现 |
| `/诡秘 重开 <出身> <天赋> [种子]` | 直接指定角色，例如 `/诡秘 重开 廷根 灵视 12345` |
| `/诡秘 选 编号\|名称\|随机` | 回答当前选择；默认 90 秒内有效 |
| `/诡秘 出身` | 查看全部可选出身 |
| `/诡秘 天赋` | 查看全部可选天赋 |
| `/诡秘 途径 [名称]` | 查看正规与外神途径图鉴 |
| `/诡秘 天骄榜` | 查看本群最强人生排行 |
| `/诡秘 帮助` | 查看内置帮助 |

## 🜏 人生如何推进

```text
出身 + 天赋
      ↓
童年与命运征兆
      ↓
非凡接触 / 平凡一生
      ↓
饮下魔药 → 扮演消化 → 晋升序列
      ↓
疯狂、危机、组织与星空的注视
      ↓
凡人 / 非凡者 / 圣者 / 天使 / 真神 / 旧日
```

- **非凡接触**：出身、天赋和命运共同决定你是否踏入神秘世界。
- **扮演法**：扮演得法会消化魔药、降低疯狂；失当则会引来污染。
- **疯狂值**：危机与晋升失败会累积疯狂，达到极限可能失控成怪物。
- **外神途径**：少数高风险天赋可能让你踏上常理之外的道路。
- **天骄榜**：以每位玩家的最佳评分记录本群传奇。

## 🖼️ 图卡输出

将 `use_image` 设为 `true` 后，插件会使用 AstrBot 的文本转图能力输出：

- **出身选择**：雾都档案 · 身份卷宗（1520px 四栏）
- **天赋选择**：灵性档案 · 命运回响（1520px 四栏）
- **人生结果**：第五纪 · 人生年鉴

人生年鉴以 **1520px 超宽画布**与三栏布局渲染：顶部采用紧凑眉题、身份栏和单行统计条，把纵向空间让给正文；中部是一篇带年龄分节的第二人称短篇。正文严格按人生时间推进，采用“先竖向读满第一列，再读下一列”的顺序，并按各段落预估高度连续分栏，减少长短列之间的大片空白。晋升之间的扮演、危机、途径经历和普通事件会按原始年龄逐条保留，最多 36 个独立年龄块。底部将结局标题、最终序列和结局正文压缩为紧凑收束区，不再占用过多高度。序列名称会在纯文本中用醒目的方括号标出，在图卡中使用途径色板高亮。无论轨迹条数或文字量，均固定为一张图片，不会自动分页。纯文本与图卡共享同一份叙事内容，图卡失败时会自动回退，不影响游玩。

序列 0 的终局不会被当作普通晋升处理：标准登神强调权柄归位；吞噬相邻途径序列 0 强调异质神性融合；吞噬源质强调自我被源头吞没；外神终点坍缩强调世界失去解释你的能力。

## ⚙️ 配置

| 配置项 | 默认值 | 说明 |
|---|---:|---|
| `use_image` | `false` | 输出超宽四栏选择图卡与按年龄推进的超宽三栏人生年鉴；高序列块会使用途径和终局主题；需要 AstrBot T2I 可用，失败自动回退同一份文本 |
| `ranking_size` | `10` | 天骄榜最多显示的条目数，建议 3–20 |
| `choose_timeout_seconds` | `90` | 每个选择点的超时秒数，建议 30–300 |

## 📦 安装

1. 在 AstrBot 插件市场安装，或从本仓库的 [Releases](https://github.com/ruoyuxian20-sys/astrbot_plugin_cyber_mystery/releases) 下载发布包。
2. 在 AstrBot 的插件管理页面选择 ZIP 安装，上传 `cyber_mystery-<版本号>.zip`。
3. 重载插件后发送 `/诡秘 帮助` 验证安装。

## 🔒 数据与隐私

排行榜按群保存在 `data/plugins/cyber_mystery/<group_id>.json`，仅包含排行榜所需的群标识、用户标识、显示名、最佳成绩与次数；**不会采集或保存聊天正文**。
