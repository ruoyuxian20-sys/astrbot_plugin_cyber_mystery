# 🌫️ 赛博诡秘

> 在灰雾、魔药与疯狂之间，重开一段属于你的诡秘人生。

`cyber_mystery` 是一款《诡秘之主》主题的人生重开模拟器：选择出身与天赋，经历随机事件、接触非凡、消化魔药，最终走向凡人、圣者、天使、真神，或常理之外的旧日。

**纯本地随机引擎 · 不调用 LLM · 不读取聊天内容**

---

## ✨ 本次版本亮点

- **16 种出身 × 16 种天赋**：从雾都贫民窟、班西灯塔到图铎遗迹；从灵视、银舌到封印物碎片。
- **更丰富的人生事件**：成长、危机、外神侵蚀、扮演、死亡与平凡晚年均已扩充，减少重复体验。
- **主题选择图卡**：出身使用「身份卷宗」风格，天赋使用「灵性档案」风格；16 项以超宽四栏布局收纳为一张图。
- **单图人生年鉴**：人生图卡固定使用超宽三栏章节布局；普通事件会智能合并，接触、晋升、危机、失控和终局等关键节点完整保留，无论内容多长都保持一张图输出。
- **可复现的随机人生**：带上种子，随机开局、角色选择与人生轨迹都会复现。

## 🚀 快速开始

```text
/诡秘 重开
```

依次选择出身与天赋后，插件会自动完成整段人生。

想立刻开局：

```text
/诡秘 重开 随机
/诡秘 重开 随机 20260817
```

第二条命令会以同一个种子完整复现随机角色与人生过程。

## 🎮 指令一览

| 指令 | 用途 |
|---|---|
| `/诡秘 重开` | 进入捏人流程：选择出身，再选择天赋 |
| `/诡秘 重开 随机 [种子]` | 随机角色并直接开始；可附种子复现 |
| `/诡秘 重开 <出身> <天赋> [种子]` | 直接指定角色，例如 `/诡秘 重开 廷根 灵视 12345` |
| `/诡秘 选 编号\|名称\|随机` | 回答当前选择；默认 90 秒内有效 |
| `/诡秘 出身` | 查看全部可选出身 |
| `/诡秘 天赋` | 查看全部可选天赋 |
| `/诡秘 途径 [名称]` | 查看正规与外神途径图鉴 |
| `/诡秘 天骄榜` | 查看本群最强人生排行 |
| `/诡秘 帮助` | 查看内置帮助 |

## 🜏 人生如何推进

```text
出身 + 天赋
      ↓
童年与命运征兆
      ↓
非凡接触 / 平凡一生
      ↓
饮下魔药 → 扮演消化 → 晋升序列
      ↓
疯狂、危机、组织与星空的注视
      ↓
凡人 / 非凡者 / 圣者 / 天使 / 真神 / 旧日
```

- **非凡接触**：出身、天赋和命运共同决定你是否踏入神秘世界。
- **扮演法**：扮演得法会消化魔药、降低疯狂；失当则会引来污染。
- **疯狂值**：危机与晋升失败会累积疯狂，达到极限可能失控成怪物。
- **外神途径**：少数高风险天赋可能让你踏上常理之外的道路。
- **天骄榜**：以每位玩家的最佳评分记录本群传奇。

## 🖼️ 图卡输出

将 `use_image` 设为 `true` 后，插件会使用 AstrBot 的文本转图能力输出：

- **出身选择**：雾都档案 · 身份卷宗（1520px 四栏）
- **天赋选择**：灵性档案 · 命运回响（1520px 四栏）
- **人生结果**：第五纪 · 人生年鉴

人生年鉴以 **1520px 超宽画布**与四章节三栏布局渲染：顶部展示人生摘要，中部按“童年与征兆 / 非凡接触 / 序列攀升 / 代价与终局”组织正文。每个章节的事件按“竖向读满第一列，再读下一列”的顺序排列，普通连续事件会合并为阶段摘要，关键节点完整保留；无论轨迹条数或文字量，均固定为一张图片，不会自动分页。纯文本也使用同一份摘要内容，图卡失败时自动回退，不影响游玩。

## ⚙️ 配置

| 配置项 | 默认值 | 说明 |
|---|---:|---|
| `use_image` | `false` | 输出超宽四栏选择图卡与章节化超宽三栏人生年鉴；需要 AstrBot T2I 可用，失败自动回退文本 |
| `ranking_size` | `10` | 天骄榜最多显示的条目数，建议 3–20 |
| `choose_timeout_seconds` | `90` | 每个选择点的超时秒数，建议 30–300 |

## 📦 安装

1. 在 AstrBot 插件市场安装，或从本仓库的 [Releases](https://github.com/ruoyuxian20-sys/astrbot_plugin_cyber_mystery/releases) 下载发布包。
2. 在 AstrBot 的插件管理页面选择 ZIP 安装，上传 `cyber_mystery-<版本号>.zip`。
3. 重载插件后发送 `/诡秘 帮助` 验证安装。

## 🔒 数据与隐私

排行榜按群保存在 `data/plugins/cyber_mystery/<group_id>.json`，仅包含排行榜所需的群标识、用户标识、显示名、最佳成绩与次数；**不会采集或保存聊天正文**。
