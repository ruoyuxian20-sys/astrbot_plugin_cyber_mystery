# 赛博诡秘（cyber_mystery）

诡秘之主主题的人生重开模拟器。纯本地随机引擎，不调用 LLM。

## 玩法

- `/诡秘 重开` —— 捏人式开局：先选**出身**（全量可选），再选**天赋**（全量可选），随即自动跑完一生
- `/诡秘 重开 随机` —— 全随机一键到底
- `/诡秘 重开 <出身> <天赋>` —— 老手直选，如 `/诡秘 重开 廷根 灵视`
- `/诡秘 选 编号|名称|随机` —— 回答当前选择点（默认 90 秒超时）
- `/诡秘 出身` / `/诡秘 天赋` —— 查看全部可选项
- `/诡秘 途径 [名称]` —— 途径图鉴：正规途径与隐秘的外神途径
- `/诡秘 天骄榜` —— 本群最强人生排行
- `/诡秘 帮助`

## 机制

- **非凡接触**：出身与天赋决定你能否踏入非凡世界
- **扮演法**：每次晋升前判定扮演成效，得法则消化魔药、平息疯狂
- **疯狂值**：危机事件与扮演失当会累积疯狂，爆表即失控成怪物或送入疯人院
- **序列爬升**：从序列 9 一路向上，高序列伴随死亡风险；序列 1 冲击**序列 0 登神**结局（低概率，需完美扮演与低疯狂）
- **外神途径**：正常人生无法踏足；选择特定天赋后有可能被引上外神途径，终点是常理之外的存在
- **旧日**：比成神更罕见的终局，世界因你而改写

## 配置

| 配置项 | 默认 | 说明 |
|---|---|---|
| `use_image` | `false` | 人生结果以图卡输出（需 T2I 可用，失败自动回退文本） |
| `ranking_size` | `10` | 天骄榜条目数 |
| `choose_timeout_seconds` | `90` | 选择点超时秒数 |

## 数据

排行榜按群存储于 `data/plugins/cyber_mystery/<group_id>.json`（原子写入），不采集任何聊天内容。
